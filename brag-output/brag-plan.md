# brag plan: agent-presence

- What: a background CLI that shows the AI coding tool you are using as your Discord activity.
- For: developers who live in Claude Code, Codex, Cursor, Antigravity or Windsurf and hang out on Discord.
- Sets it apart: one tool for all agents, and you install it by giving your agent one sentence.
- Funniest claim: your friends' status says Valorant, yours says Claude Code.
- Visual hook: a Discord member list where everyone is gaming and you are coding.
- Real things shown: the copy-paste agent prompt from the README, real CLI commands and output, the real activity fields (app name, details, logo, elapsed timer), the real logos.
- Tone: default (punchy, playful, clean). Landscape 1920x1080, 30 fps, 20.5 s.
- Share caption: Your Discord status can say Claude Code now.

## Identity

Discord dark palette (#1E1F22 / #2B2D31 / #313338, blurple #5865F2, online green #23A55A), Inter for UI and headlines, JetBrains Mono for terminal and wordmark. Tool colors come from the logos.
